# fluent-challenges

Solidity + Rust smart contract challenges for developers on Fluent.
Visit Fluent's Discord channel biweekly for new challenges.
The most high quality valid submission wins $250!

Note: there can be multiple winners if there are multiple submissions that meet all requirements.

# Submission Requirements

```
-You did not win the last Fluent Challenge 
     (for example if you won challenge 2, you cannot do challenge 3, but you can do challenge 4)
-Complete all challenge requirements that are not marked as optional
-Create a private repo and share it in the Fluent challenges Discord
-Document Solidity and Rust contracts with their deployment scripts and addresses verified
-Create an interactive hosted frontend link using React + Vite with setup commands documented
-YouTube video link for pull request submission (60 seconds long max)
-Submissions open at Thursday 5PM EST (please make sure all requirements are met and tested and try to polish as much as possible)
```

# Instructions

1. Go to challenges/new to find new Fluent challenges.
2. Follow the requirements in the README above and in the new challenge.
